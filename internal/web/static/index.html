Git 管理

管理你的提交身份和仓库连接，在多个工作空间复用。

系统设置

账号池与服务端配置的集中维护入口。改动写入 config.json，多数即时生效。

账号池

创建工作空间时可选用的订阅账号与 API Key。多个空间可共用账号，登录凭证由服务器统一管理和同步。

IP 代理

账号级别的出口代理池。账号绑定其中一个后，它的全部官方请求——容器里 agent 发的，以及服务端代发的登录与探测——都从这个 IP 出去。在「账号池 → 编辑」里绑定。

读取代理列表…

代理池为空。点击右上角「添加代理」或「导入」添加第一个出口。

桥接监听

容器里的 claude 是 Node 客户端，只认 http(s) 代理、不认 socks5，所以 agentbox 在本机起一个 HTTP 代理替容器走完 SOCKS5 那一段。监听地址必须是容器能连到的宿主机地址，默认是 docker 网桥网关。改动即时生效。

代理池非空时自动启动；绑定失败只影响代理功能，不影响服务

容器与资源

设置工作空间使用的容器镜像与资源上限。保存后，新启动的空间会应用设置；运行中的空间需停止后再启动。

客户端更新

按系统时区调度；stable 可能落后于 latest。切换渠道不会自动降级。

空闲自动停机

工作空间没有进行中的对话或终端连接，达到设定时长后会自动休眠，释放内存与 CPU。文件和对话保留，发送消息或连接终端即可唤醒。设为 0 可关闭自动休眠。

即时生效，无需重启；0 表示永不自动停机

Agent 权限模式

内网反向隧道

本机 abox-link 连接后，工作空间可访问你放行的内网服务。两种模式都通过同一条隧道，按用户隔离，并由本机白名单控制。

透明模式（默认，推荐）：对话与终端直接使用内网 IP 或域名，无需 Agent 配置代理，支持 IPv4 / TCP。首次启用需先准备网络辅助镜像。

内网隧道

          
在你的电脑上运行 abox-link，让云端工作空间中的 Agent 按需访问你授权的内网服务。

        


        

          

            
            

              离线
              
            

          

          

          

            
访问模式

            

            
透明模式 · 默认推荐：直接访问放行的内网 IP 或域名，对话与终端无需配置代理。支持 IPv4 / TCP。

            
兼容代理模式 · 暂不推荐：保留给旧客户端或特殊场景；需要显式使用 SOCKS 代理，数据库等程序通常要另配端口映射，Agent 可能因漏用代理而连接失败。

            
两种模式都需要本机 abox-link 在线并配置白名单。旧客户端不会自动切换；请下载新版客户端，在本机开启透明模式并保存重连。
