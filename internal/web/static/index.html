空闲自动停机

会话在无活动（没有对话进行、没有终端连接）达到设定时长后，自动停止其容器以释放内存与 CPU。工作区文件不受影响，下次对话或连终端时会自动重新拉起。设为 0 关闭自动停机。

即时生效，无需重启；0 表示永不自动停机

修改登录密码

修改当前管理员账号的登录密码。修改后本端保持登录，其他已登录端下次请求起需重新登录。

密码保存在服务端数据库（PBKDF2 哈希），不再依赖 config.json 的 auth_token

  1. 下载 abox-link 客户端（放到你自己的电脑上）
