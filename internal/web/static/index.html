    了解更多

    容器里的 Claude Code 只认 HTTP(S) 代理、不认 SOCKS5，所以服务端在本机起一个 HTTP 代理，替容器走完 SOCKS5 那一段。默认监听 docker 网桥网关。

    包括容器里 Agent 发出的请求，以及服务端代发的登录与探测，都会经过所绑定的代理。

    代理池非空时自动启动；绑定失败只影响代理功能，不影响服务

    了解更多

    两种模式都走同一条隧道，按用户隔离，并由本机白名单控制。

    透明模式（默认，推荐）：对话与终端直接使用内网 IP 或域名，不需要给 Agent 配代理，支持 IPv4 / TCP。首次启用需先准备网络辅助镜像。

    兼容代理模式（不推荐）：取消下方勾选后使用。Agent 要显式使用 SOCKS 代理，不支持代理的程序要配置端口映射，容易漏用，只给旧客户端或特殊场景。

    默认绑定 docker 网桥网关 172.17.0.1，仅容器与本机可达

    内网隧道

    在你的电脑上运行 abox-link，让云端工作空间中的 Agent 按需访问你授权的内网服务。

    离线

    访问模式

    透明模式 · 默认推荐：直接访问放行的内网 IP 或域名，对话与终端无需配置代理。支持 IPv4 / TCP。

    兼容代理模式 · 暂不推荐：保留给旧客户端或特殊场景；需要显式使用 SOCKS 代理，数据库等程序通常要另配端口映射，Agent 可能因漏用代理而连接失败。

    两种模式都需要本机 abox-link 在线并配置白名单。旧客户端不会自动切换；请下载新版客户端，在本机开启透明模式并保存重连。

    透明内网访问

    隧道功能未启用。启用后，你可以在自己的电脑上运行 abox-link 客户端， 让云端容器里的智能体访问「只有你本机能连」的内网（公司内网、局域网设备、本地数据库）。

    接入步骤

    1. 下载 abox-link 客户端（放到你自己的电脑上）
      此服务尚未安装客户端，请从 官方发布页 下载对应系统的 abox-link。一键安装 v0.1.1 起自动提供下载。
    2. 双击运行，它会自动打开本机控制台 http://127.0.0.1:7801
    3. 粘贴配对码完成接入——不用输服务器地址和密码。 之后在控制台里点选放行规则、点「启动」即可，还能勾选开机自启。
