## 多端改动

此前 Rust 空间类型丢弃 `stop_reason`，桌面把空闲回收后的空间显示为已停止。现在网页与桌面复用纯状态函数：running 优先于旧 stop_reason；停止且 idle 显示休眠，其余显示已停止。文件与历史保留、进入终端自动启动的说明一致。旧服务端缺失 stop_reason 仍可读取。

桌面原生 JSON、上传/下载及终端握手失败层只转发长度/字符集校验后的 `code`、32 位小写十六进制 `operation_id` 和布尔 `retryable`，不转发服务端/代理原始 error、hint、路径或凭证。renderer 按已知错误码显示与网页相同的三语解释和下一步；未知码/旧服务端沿用安全的本机 HTTP 提示。显式不可重试可阻止终端自动重连，不能凭 retryable=true 扩大旧有重连范围，也不让同步写入自动重试。常见原生网络/HTTP 提示按 kind＋固定文案白名单翻译，其他原生错误字符串继续按原样显示，不把任意外部文本当翻译键。已建立 WS 的关闭消息仍保留原始语义，本批没有改变关闭码或自动重连策略；尚未声明所有本机文件/系统错误已本地化。

## 试用准备与退出条件

试用开始前记录匿名参与者、负责人、服务端/桌面/Agent 镜像版本与 schema、系统/架构/文件系统、可接受的数据范围、已验证备份和恢复方式、开始/计划结束日期。只接纳自愿参与者，至少观察一个完整迭代周期；当前没有招募或对外发送消息。

管理员在测试实例显式开启同步，参与者再次确认本机目录和同步计划。退出时先暂停计划并核对在途结果，再使用现有解除绑定/恢复入口；保留待核对操作、恢复记录与副本，不因结束试用自动清理或回滚用户文件。

每次事件只记录匿名编号、版本组合、时间、冲突/恢复/支持请求类别、操作编号、内容哈希核对结果及解决状态，不收集提示词、文件正文或凭证。模板：

| 试用编号 | 版本/设备组合 | 日期/观察周期 | 冲突及恢复结果 | 支持次数 | 未解决问题/退出结果 |
| --- | --- | --- | --- | --- | --- |
| 尚无实际样本 | 待落实 | 0 个完整周期 | 未开始 | 未记录 | 不计作通过 |

未解决的数据丢失、权限越界、重复扣费或启动失败阻止稳定发布，先暂停受影响试用并保全证据。缺签名/公证/最低系统或正式升级证据时继续标记测试版；发布动作不自动开启任何生产同步配置。

## M5-03 后续开发批次（2026-10-05）

本批完成错误链路与动态语言显示的补齐，M5 整体仍未完成；M4 的剩余拆分/稳定性与恢复验收也未关闭，不能把进入 M5 记为前序里程碑已全验收。

- JSON API、附件/目录上传、下载共用受限错误读取。只解析 application/json，正文最多 16 KiB、额外读取最多 2 秒；超限、截断、非 JSON 或停顿回退到已知 HTTP 状态，保留有效响应头操作编号，不把错误页面当下载内容。
- 终端 WS 握手失败使用同一字段白名单及响应头编号回退，只解析不超过 16 KiB 的已有错误正文；原 70 秒连接期限保持，未把 HTTP 正文的 2 秒期限冒充 WS 整体期限。正文中合法编号优先，缺失/不合法才用合法响应头。
- 登录/配对的旧错误重分类保留已有安全编号。成功传输、单次票据、取消、同步写入和终端重连的授权规则不变，不因错误字段而自动重试写入。
- `errorNotice` 只捕获固定错误码、操作编号和安全本机提示；`messageRef` 在读取时翻译，嵌套的恢复说明也随语言更新。`errorMessage` 保留给确实需要字符串快照的调用方。更改原错误对象不能改写已经捕获的编号/含义；用户路径和任意原文不翻译。
- `desktop/src/native-problems.json` 列出常见 HTTP/网络的本机固定提示，kind 和文案必须同时匹配才翻译；Rust 与 TS 回归核对目录。未知码继续安全回退，不把任意服务端文本当本机翻译键。
