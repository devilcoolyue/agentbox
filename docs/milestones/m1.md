## M1-01：管理员离线密码恢复

交付命令：

```bash
agentbox admin-reset-password --config /实际配置/config.json --user boxadmin
```

仅当前源码包含此命令，不保证旧发布包支持。详细停服、备份、恢复与重登流程见[排障手册](../troubleshooting.md#忘记密码或改了-auth_token-仍不能登录)。

实现边界：

- 显式指定配置和现有管理员；取得服务使用的数据锁，在锁内重新加载配置，并在输入后再次核对数据目录。不会自动停服务、创建管理员或提权。
- 仅打开已有且 schema 与二进制一致的数据库；不创建空库、不迁移、不导入旧 JSON、不更改 journal 模式。维护连接使用 `synchronous=FULL`。
- 与网页登录共用原 PBKDF2 格式；新增独立生成的旧格式已知值回归。两次从控制终端隐藏输入，不从 argv/env/stdin 读取密码。
- SIGINT/SIGTERM、输入不一致或读取失败时不修改密码；取消后清空未提交输入并恢复终端回显，防止残留密码进入调用者 Shell。
- 更新密码与撤销目标管理员全部登录令牌复用现有 SQLite 事务；故障注入确认撤销失败会回滚密码。其他用户令牌、配置、空间元数据、用量、额度与账本保持不变。

验证入口与边界：

| 类型 | 入口 | 覆盖 |
| --- | --- | --- |
| 离线行为回归 | `go test ./cmd/agentbox -run TestAdminPassword -count=1 -v` | 临时配置与真实 SQLite；锁、目标、取消、配置变化、回滚、数据不变；有 Python 3 时含真实 main 入口的伪终端输入/信号验收 |
| 离线数据库边界 | `go test ./internal/store -run 'TestMaintenance\|TestPasswordReset' -count=1` | 不创建/迁移、不改 journal、不导入 JSON、FULL 持久化、原有令牌事务并发回归 |
| 密码兼容 | `go test ./internal/password ./internal/server` | 旧 PBKDF2 格式兼容、既有网页登录/改密与鉴权回归 |
| 并发检测 | `go test -race ./cmd/agentbox ./internal/store ./internal/password` | 命令、数据库与密码实现，包括伪终端子进程 |
| Linux 隔离验收 | `./scripts/test-admin-password-linux.sh` | 临时 Linux 容器、UID 1000、禁外网、无宿主挂载；复制交叉编译测试与 Python 夹具，执行真实终端及数据库回归；结束清理容器 |

Linux 入口复用已有 `agentbox-client-test:local` 镜像；没有镜像时按下方开发文档先构建。该测试不运行真实 systemd，也不模拟生产数据恢复；实际部署操作仍应遵循排障手册。

## M1-03/04：分层环境检查与六类合成故障

- 配置、Docker、指定镜像、磁盘、写入/属主、账号、授权/额度、WS 和模型各自标记通过/失败/未检查。没有“整体通过即模型可用”的推断。
- 临时写入探测仅用于主动实例检查；空间检查持原 workspace 锁、固定目录句柄、只读根目录元数据。真实 Linux chown 拒绝保持为失败，不放宽生产权限。
- 空间报告不含实例计数/容量、路径或其他用户信息；撤权后不读取账号凭证。普通用户和管理员均不能用空间接口读取他人空间。前后端报告字段和文案均做白名单处理，畸形枚举不能被渲染成通过。
- 服务端报告保留 WS 未检查；浏览器确实收到匹配响应后才另记 `client_checks`。服务端 sent 日志不代表浏览器已收到。检查窗口支持取消/重试/关闭清理，CLI 中断返回非零。

每条只记录匿名参与者编号、版本/客户端、角色、测试设备、预置条件、任务开始/首次结果/完成时间、失败类别、首次有效定位时间、是否借助口头提示与最终结果。不得附提示词、源码、账号令牌、真实文件或数据库。
