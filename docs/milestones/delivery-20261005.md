## 2026-10-06 GitHub 风格 Markdown 预览

文件预览原先复用聊天流的轻量文本渲染器；它只覆盖少量对话语法，因此 README 中的 `<div align="center">`、嵌套徽章图片、表格和部分链接会落成原始文本，视觉层级也与 GitHub 不同。

现改为独立 GFM 渲染链：Marked 18.1.0 解析、DOMPurify 3.4.16 白名单清洗、GitHub Markdown CSS 5.9.0 的浅色/深色样式；相对图片和文档链接限制在当前 workspace/shared 根，外链不携带控制台令牌。标题锚点、任务列表、代码块、表格、徽章、居中 HTML、README 图片和移动端换行均覆盖。脚本、iframe、表单、事件属性及 javascript URL 不会进入预览 DOM。
