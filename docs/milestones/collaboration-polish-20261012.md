# 时序动效与问答样式修正

日期：2026-10-12。状态：已发布生产 `v0.1.12-dev.collaboration.20261012.14`，只读生产验收通过。

## 变更

- SVG 不再通过不同轴比例拉伸 viewBox；泳道实际 CSS 宽度驱动绘图坐标，节点保持正圆。
- 绘线与运动关键帧来自同一折线。正向、反向、自环均按各段长度线性推进，包含自环的出发、转弯、返回三段。每条箭头动画 1.1–1.8 秒，重放等待当前箭头结束后推进，隐藏状态事件快速略过。
- 光点使用 HTML 圆点叠加 SVG 绘线，避免 WebKit 对 SVG CSS transform 再乘一次 CSS zoom 的实际偏移。ResizeObserver 只排队下一帧更新，不在回调同步改布局；调整大小保留动画进度。
- 暂停、切标签、关闭、隐藏页面、切任务和减少动效偏好控制实际 Animation；返回过程恢复运行中的提示。移除遮挡图形的大段 hover 提示，详情继续点击查看。
- 用户需求在右侧气泡中，标注“你 · 任务需求”；协作回复左对齐，品牌、状态、主辅模型分清。移除协作外框和竖线，保留最终结果、验证、操作及费用。
- 删除侧栏“协作任务”按钮；保留空间内发送模式、过程、结果与异常任务的管理入口。面板兼容按钮不存在，并等待既有初始化完成后处理程序化打开。

不改变协作调度、任务数据或计费。重放不调用模型、不重新执行步骤。
