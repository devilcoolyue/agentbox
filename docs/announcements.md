# 系统通告

[返回文档目录](README.md)

管理员可以向所有登录用户在页面顶部显示一条横幅，最常见的用途是提前告知发版维护：用户看到倒计时，能先保存进度、不在那段时间开始长任务。

## 两种通告

| 类型 | 横幅内容 | 何时消失 |
| --- | --- | --- |
| 发版维护 | 到点前：「计划于 10-24 23:00 发版升级（还有 8 分钟），预计中断约 2 分钟……」；到点后：「正在发版升级，页面和终端可能短暂断开」；新版本启动后：「服务已升级到 vX，可以正常使用」 | 升级完成 10 分钟后；从未完成的，计划时间 24 小时后不再显示 |
| 普通通知 | 「管理员通知」加通告内容 | 管理员撤下 |

同一时间只有一条通告，重新发布会替换旧的。内容是纯文本，最多 500 字；发版通告的内容可以留空。用户可以点 × 收起，同一条通告不会再弹出；重新发布或升级完成后会再次显示。

「升级完成」由新服务自己判断：服务启动时，如果有一条在启动前发布、尚未完成的发版通告，而当前版本与发布时运行的版本不同，就把它标成已完成。只是重启、版本没变时保持原样。通告是由不知道旧版本的方式写入的（例如手工执行 `agentbox announce` 而没带 `--from-version`）时，以「启动时间晚于计划时间」作为完成条件。

## 在网页上发布

「系统设置 → 系统通告」（仅管理员）：

- **当前通告**：预览所有人看到的横幅，可以撤下。
- **发布通告**：选类型；发版维护再选计划时间（5 分钟后到 1 小时后，或指定时间）和预计中断分钟数。发布后已打开的页面几秒内就会显示。
- **现在重启会影响谁**：开着页面的用户（每个标签页一条推送连接）；挂着终端或对话连接、有网页对话回合在运行，或 30 分钟内用过的工作空间。列表为空时，现在发版不会打断任何人。每 15 秒刷新一次。

终端里由 Agent 自己运行的长任务不算「对话回合」，只体现在终端连接数和最后活动时间里；判断时一并参考。

## 在服务器上发布

发布脚本不需要登录：

```bash
# 查看当前通告
sudo /opt/agentbox/current/agentbox announce --config /etc/agentbox/config.json
# 10 分钟后发版、预计中断 2 分钟
sudo /opt/agentbox/current/agentbox announce --config /etc/agentbox/config.json \
  --release --in 10m --duration 2 --message "本次更新：登录限速修复" --from-version v0.1.17
# 普通通知 / 撤下
sudo /opt/agentbox/current/agentbox announce --config /etc/agentbox/config.json --notice --message "今晚 22:00 起主机维护"
sudo /opt/agentbox/current/agentbox announce --config /etc/agentbox/config.json --clear
```

`--at 2026-10-24T23:00:00+08:00` 可代替 `--in` 指定时间。命令直接写数据目录里的文件，运行中的服务约 3 秒内发现并推送给所有页面。

`release.py activate` 可以把预告和发版串起来：

```bash
sudo python3 /opt/agentbox/current/deploy/release.py activate --version v0.1.18 \
  --announce-minutes 10 --announce-duration 2 --announce-message "本次更新：登录限速修复"
```

它先做与平时相同的兼容检查，通过后用新版本的程序发布发版通告（自动带上当前运行的版本），等待指定分钟数（1–120），再检查一次后照常停服务、备份、切换、启动。停服务之前任何一步失败都会撤下通告，不会留给用户一个不会发生的倒计时。等待期间持有部署锁，按 Ctrl+C 中止也会撤下通告。

## 存储与边界

- 通告存在 `<data_dir>/announcement.json`，不在数据库里，所以不改变 schema，不影响回退到旧版本。
- 这个文件**不进系统备份**：从备份恢复时不应带回一条过期的「即将发版」横幅。
- 横幅变更通过 `/api/usage/live` 推送连接到达，登录后的每个页面都保持这条连接；连不上时页面每 2 分钟读一次，切回标签页时也会读一次。
- 横幅只出现在已登录的网页上；桌面客户端、abox-link 和终端里不显示。旧版本服务端没有这个功能，第一次升级到支持它的版本时预告不会显示。

接口见 [API 文档](api.md#系统通告)。
