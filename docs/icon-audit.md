# 按钮图标语义审阅

审阅日期：2026-09-27。本文保留图标统一前的审阅快照；后续已按 [图标收敛约定](button-design.md#2026-09-27-图标收敛) 实施。以下依据审阅时工作区源码，包含尚未提交的改动；范围是主控制台和 abox-link 本机面板，不含容器内第三方 CLI 自身的界面。

打开 [图标对照页](icon-audit.html)，可以直接对照实际图形、按钮含义、建议及源码位置，搜索按钮名、图标名或文件名。页面独立运行，不需要服务端或登录。

## 是否全部使用 SVG

不是全部，但主要操作图标确实使用 SVG。没有发现主控制台依赖外部图标字体；共享图标路径直接保存在源码中，不能仅从路径认定它们来自某个特定图标库。

| 来源 | 当前实现 | 范围 |
|---|---|---|
| 共享 SVG | `web/src/icons.ts`，56 种图形；`data-icon`、`svgIcon`、`buttonLabel`、`actionButton` 添加 | 主控制台多数操作 |
| 内联 / 模板 SVG | `internal/web/static/index.html`，直接定义 path、rect、circle 等 | 导航、页签、附件、语音、发送、主题、日历等 |
| 独立 SVG | `internal/linkapp/static/app.js`，8 种图形 | abox-link 面板 |
| CSS 图形 | border 三角形、旋转边框 | 使用记录排序、加载状态 |
| 字符 | `?`、`↑ ↓ ← →`、`⇧` 等 | 费用明细、终端快捷键；文件类型标识也使用字符 |
| 纯文字 | 取消、日期数字、模型名等 | 不需要图标的操作或选择控件 |

当前两个 HTML 页面分别有 **207 个、7 个静态 button 定义**，另外在 TS 模板中提取到 **53 个 button 定义**。对照页逐项列出这 267 个定义，并另列主要动态列表动作、状态切换及共享图标调用位置。这些数字不是同时可见的按钮数量，也不包括运行时按文件、账号、模型等数量生成的所有实例。

`docs/button-design.md` 中的 170 个主页面静态按钮统计和「填入官方价」清单已不能代表当前工作区；本次以代码为准。当前价目表的「应用」已使用 check，不应再作为下载图标误用的例子。

## 优先调整的语义

| 按钮 / 位置 | 当前图形 | 问题 | 建议 |
|---|---|---|---|
| Git 拉取 | refresh 双箭头圆环 | 与同排「刷新」同图，但拉取会合并并更新文件 | 专用 Git pull 图形，并保留文字 |
| 技能 → 我的模板 | users 多人 | 实际是当前用户的个人模板，不是成员管理 | 文件模板 / 带书签文件夹 |
| 文件 → 共享目录 | users 多人 | 当前是同一用户多个空间共享，容易误认成多人共享 | 带链接的文件夹，明确共享范围 |
| abox-link → 解除绑定 | close 叉号 | 容易误认成关闭界面或取消 | 断链，保留解除绑定文字 |
| 版本 → 查看更新 | download 下载 | 实际打开更新信息，不直接下载 | info / 发布说明 |
| 撤销 OAuth 授权 → 确认 | trash 垃圾桶 | 通用确认框把所有 danger 操作都自动配成删除 | 按动作传图标；风险单独用颜色表达 |

尤其应先处理同一工具栏里的碰撞：Git 的刷新 / 拉取、管理连接 / 终端授权，以及技能的安装 / 下载。隐藏文字后，工具提示虽然能补充说明，但第一次看到图标时依然难以区分。

## 其余值得统一审阅的语义

| 按钮 | 当前图形 | 建议方向 |
|---|---|---|
| PR / MR 管理 | external 外链 | 内部弹窗入口使用 PR / merge 图标；外链留给真正跳转 |
| Git 操作记录 | activity 脉冲 | 改历史 / 列表；与连接测试、监控区分 |
| 设置提交身份 | commit 提交节点 | 改 user，避免被理解成执行提交 |
| 绑定 Git 连接 | save 磁盘 | link 更能表达建立关联 |
| 安装技能 | download 下载 | 安装包加号与下载文件区分 |
| 官方技能市场 | box 箱子 | 市场 / 商店 / 插件图形，与空间、容器区分 |
| 使用记录 | 趋势折线 | 明细列表 / 账单更贴近流水页面 |
| 退出登录 | 电源 | 向外的门箭头，与登录成对 |
| 密码显示切换 | 隐藏时 eye-off，显示时 eye | 当前图形表示状态，提示表示下一步动作；需统一状态 / 动作表达规则 |

这些属于设计判断，不是功能错误。带明确文字时，一部分复用可以接受；纯图标呈现时应更严格。

## 样式差异

- 共享图标中多数使用 24×24 视框、1.8 描边；`tool/copy/check/caret/chevron` 使用 18×18、1.5 描边。内联图标还有 16 / 18 / 24 视框及 1.5 / 1.6 / 1.8 / 1.9 / 2 描边。参数不同不必然有问题，需要在相同显示尺寸下比较视觉粗细和留白。
- 终端「重新连接」是单箭头圆弧，对话「立即重连」是双箭头圆环。同一动作出现不同形状。
- 日期选择器的内联日历有圆角和日期短线，共享 calendar 是直角外框；文件夹、分支、左右箭头也存在不同母版。
- 工作空间停止是空心直角方框，对话中断是实心圆角小方块。可以有意区分操作层级，但应形成规则。
- abox-link 单独维护图标路径；多数与主站接近，垃圾桶提手已经存在细节差异。
- `.action-tools` 会隐藏文字，图标显示为 18px；桌面点击区域 32px，触屏 44px。原本图文组合能表达清楚的业务动作，在此规则下可能产生歧义。

## 可以直接保留的映射

| 动作 | 图形 |
|---|---|
| 新建 / 添加 | plus |
| 启动 / 停止 | play / stop |
| 删除对象 | trash |
| 编辑 / 重命名 | rename 铅笔 |
| 复制 / 复制成功 | copy / check |
| 保存 | save |
| 上传 / 下载文件 | upload / download |
| 预览 / 源码 | eye / code |
| 关闭弹窗 | close |
| 新标签页打开 | external |
| 全屏 / 还原 | expand / collapse |
| 用户余额 / 订阅额度 | wallet / gauge；两者含义不同，可保留区分 |

建议统一规则：一个动作保持一个图形；同排不同动作避免同图；图标选择与危险颜色分离；复杂业务操作保留文字。不是每个按钮都必须加图标，也不是所有 SVG 都必须机械地使用相同参数。

## 审阅边界

本次只新增对照文档，未调整产品图标。图形从源码提取；对照页统一为 22px 方便比较，不是运行中各页面的布局截图。动态操作按动作归组，模板中的表达式保留源码形式；具体权限、加载态和业务状态下的页面仍需在最终调整时验收。
