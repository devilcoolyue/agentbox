# 工作空间使用指南

[返回文档目录](README.md) · [项目首页](../README.md)

## 第一次使用

1. 使用管理员分配的用户名与密码登录。v0.1.11 起首页提供「首次使用指南」：管理员先检查环境、接入账号并确认默认模型；普通用户查看获准使用的账号，没有账号时联系管理员。
2. 创建工作空间，选择 Agent 和同类型授权账号，核对模型和新容器资源上限；如提示配置变化，核对后继续。v0.1.11 可直接选择空项目、上传项目或 Git 导入；失败后在同一个空间重试，确认丢失先查询状态，详见[创建与项目导入](project-creation.md)。
3. 检查导入结果；已有空间仍可从「文件」上传或用 Git 连接克隆到 `/workspace`。创建导入只发布到新目录，不覆盖原目录。
4. 工作台「首个任务与交付」可将示例放入对话框，修改目标、涉及文件和验收条件后自行发送。
5. 查看项目文件；有 Git 时审查「变更」中的 diff，确认后提交，再从「远程」执行推送。也可以直接下载工作区 ZIP。
6. 暂时不用时停止空间；以后重新启动，文件和对话记录继续保留。

创建窗口会重新读取账号权限，并在提交前再次核对；只拥有一种 Agent 的账号时自动选择该类型。没有授权账号或读取失败时不能提交空账号表单，可配置账号或刷新重试。指南中的凭证存在只表示本地配置，环境检查也不代表模型已经验证。

账号池为空时，请管理员先添加账号。账号与模型的可用性由对应订阅、API 或中转服务决定，模型出现在列表中并不代表该账号一定能调用。

## 导航与登录

控制台用 URL 保存当前页面，例如 `#/usage`、`#/settings/container`、`#/sessions/<空间ID>/files`。刷新、前进 / 后退或重开收藏链接会恢复页面；未登录时先登录再恢复，失效或无权访问的目标返回首页。`#` 路由不需要额外反向代理配置。

登录和身份读取限时 15 秒，失败时显示可重试错误。密码默认隐藏，可用眼睛按钮切换，重新进入登录页时恢复隐藏。侧栏底部的图表图标打开「使用记录」，链条图标打开「内网隧道」。

手机端只保留顶部页面标题，系统设置与 Git 管理通过右上角下拉选择子菜单，选择后自动收起。分区介绍可点「说明」展开。工具栏按钮仅显示图标，长按可查看名称；低频操作在「更多」中，保存与删除等确认弹窗保留文字。桌面端保留左侧分区导航和文字操作，较窄窗口按可用宽度调整布局。

操作提示出现在页面中上方，使用状态图标与倒计时细线；错误提示停留更久，打开对话框时仍可看到。使用记录、设置与隧道页在各自内容区滚动。

## 查找工作空间

侧栏可按空间名称搜索，并叠加「运行中 / 休眠 / 已停止」筛选。名称按部分文字匹配，不区分英文大小写，兼容全角字母；只搜索空间名称。计数显示匹配数与总数，点击「清除筛选」恢复完整列表。状态使用服务端最近一次刷新结果，休眠指空闲自动停机。

筛选不会关闭当前空间，首页最近空间和对话内的线程标题搜索独立保留。搜索条件只存在于当前登录页面，刷新或退出后清空；桌面收起侧栏时可点搜索图标展开，窄屏可在菜单抽屉内搜索后切换。搜索框内按 Esc 先清除文字，再按 Esc 关闭窄屏抽屉。

## 空间、线程与账号的关系

| 概念 | 保存什么 | 与其他资源的关系 |
| --- | --- | --- |
| 工作空间 | 项目文件、home 配置、终端环境与聊天历史 | 绑定一种 Agent 和一个账号，对应一个容器 |
| 对话线程 | 单独的对话上下文和历史 | 多条线程共用空间文件；切换线程不会回滚代码 |
| 账号 | 订阅凭证或 API / 中转配置 | 一个账号可被多个空间使用 |
| 共享目录 | 需要跨空间使用的文件 | 同一用户的空间共享，其他用户独立 |
| 用户模板 | 技能、MCP 和常用 home 文件 | 在该用户的空间启动时叠加 |

界面使用「工作空间」这个名称，API 和数据模型沿用 `session`，两者指同一资源。

## 创建、休眠与删除

创建空间时保存当时的系统默认模型；以后管理员调整默认模型，不会更改这个空间保存的值。需要更换 Agent 类型时，创建对应的新空间，可借助共享目录传递项目；只换账号时，在空间的 ⋯ 菜单选「切换账号」，改用同类型的另一个授权账号，见[切换空间账号](accounts-and-models.md#切换空间账号)。

| 操作 | 容器与进程 | 数据 |
| --- | --- | --- |
| 关闭浏览器 / 网络断开 | 容器不会因此立即停止；终端可重新附着 | 保留 |
| 手动停止 | 停止容器及其进程 | 保留 workspace、home 和对话 |
| 空闲休眠 | 默认无活动 30 分钟后自动停止 | 保留，再发消息或打开终端可唤醒 |
| 切换账号 | 先停止容器及其进程，运行中的空间切换后重新启动 | 保留 workspace、home 和对话，之后改用新账号 |
| 删除空间 | 删除容器与列表入口 | 默认保留磁盘上的空间目录 |
| 删除并清除数据 | 删除容器与列表入口 | 同时删除该空间的文件、home 和对话 |

空闲检测会保护正在执行的网页对话和已连接的终端。终端断开后，tmux 中的后台进程不构成永久保活；若需要长时间无人值守运行，请与管理员确认空闲停机配置。

默认删除留下的数据不会自动重新出现在空间列表里，需管理员从磁盘提取或按备份恢复流程处理。用户共享目录不属于某个空间目录，不随单个空间的清除一起删除。

## 对话

「对话」页用于任务式交互：发送消息、读取流式输出、查看工具调用，在需要时中断当前回合。

- 同一空间可创建多条线程，按标题搜索历史、重命名和切换；每条线程保存自己的 provider 会话 ID 用于续聊。
- 同一空间最多 3 条线程可以同时运行，各自是容器里一个独立的 CLI 进程，上下文互不影响。一条线程在跑时照样能新建、切换线程并在别的线程里发消息；切走不会中断它，切回来接着看进度和计时。
- 对话切换栏旁的「N 个运行中」标出别的线程还在跑，历史列表里正在运行的线程带转圈图标。后台线程完成、出错或在等你回答问题时会弹出提示。
- 已有 3 条线程在跑时，在空闲线程里发出的消息先排队，有线程结束就自动开始；运行中的线程不能删除。
- 同一线程同一时刻只运行一个回合，运行中继续发送的消息排队或插入当前任务。多个浏览器连接该空间时各自停在自己看的线程上，不会被别的页面的切换带走。
- 模型选择可使用候选项或自定义模型 ID，浏览器按空间记忆选择。对话中选模型不修改终端的默认模型。账号配置了可用模型时只能在这些模型中选择，思考强度只对支持调整的模型显示，并只列该模型的档位；没有手选时直接显示并使用默认档位（如 High），不再有「默认强度」项。管理员可在「系统设置 → 模型管理」关闭不常用模型的显示，模型仍保留在账号里，随时可以重新打开。
- 推理选项按模型与账号能力显示，切换模型会清除不兼容的选项；Claude 原生推理强度与旧思考预算分别适配，详见[账号与模型](accounts-and-models.md#推理强度与思考预算)。
- 「思考过程」显示的是模型服务提供的思考摘要，不是原始推理：Claude 与 Codex 只开放摘要，按段流式到达，常为英文；模型或中转不返回摘要时不显示思考框。DeepSeek 等直接返回推理原文的接口照原样显示。
- 每轮回答底部显示系统时区的时间、模型、当时的推理设置和已入账费用，可一键复制 Markdown 正文（不含思考与工具日志）。新回合保存设置快照；旧记录缺失字段标为未记录，未指定强度显示跟随默认。
- 费用与「使用记录」同源，标明 CLI 报价或价目表来源；没有价格显示「未定价」。历史费用不随价目表调整而重算，也不等于订阅额外扣费或中转站账单。无法关联回合的旧 Claude 记录仅展示 CLI 报告值，旧 Codex 记录缺失费用不猜算。
- 电脑上空间运行中、对话已有内容时，顶部的空间标题行和标签栏自动收起，对话切换栏顶到最上方，左侧显示空间名。鼠标停在空间名上（或点击、键盘回车）时顶部栏浮在对话上方展开，移开或按 Esc 收回，正在看的内容不会被挤动；从浮层切到终端、文件等页时顶部栏恢复常态。浮层右上角的按钮可固定显示顶部栏，固定后同一按钮再次收起，选择保存在当前浏览器。空间已停止或休眠、空对话和手机端不收起。
- 上滚查看旧消息后，可使用输入框上方的按钮返回最新消息。
- 断线后页面自动退避重连，并补拉遗漏的完整消息。历史加载失败时先点重试，恢复前发送会暂停。
- 历史记录按页加载，向上滚动可继续查看更早内容，不再只显示最后 2000 条。打开空间和加载更早历史的等待期限默认为 120 秒，管理员可在「系统设置 → 安全与访问 → 历史加载超时（秒）」调整（1–3600 秒），其他已打开的页面刷新后生效；切换空间、线程或退出会取消旧请求。
- 回合进行中，执行指示旁逐秒显示已用时间，中途打开或刷新页面也接着计；结束后回答底部显示本轮总用时（从开始到结束的墙钟时间，含容器与 CLI 启动），历史记录里同样保留。

网页对话与终端中的 CLI 共享文件，但不自动共享一份对话上下文。新建线程适合开始新的讨论；需要隔离依赖或代码时应新建空间。

同时运行的线程共用同一个 `/workspace`：可以让一条线程写计划或交接文档、另一条去读，借此分工推进一个大任务。几个 Agent 同时改同一个文件会互相覆盖（Claude Code 发现文件在它读过之后被改过，会先重读再改，但通过命令修改的不在此列），也可能同时操作 Git，请按目录或文件分工；需要完全隔离时，在终端标签里用 `claude -w <名字>` / `codex --worktree` 在独立的 git worktree 中工作。委派（跑腿模型）同一空间同时只给一条线程用，另一条线程的消息按普通对话执行并给出提示。

### 执行过程：任务列表与上下文占用

**任务列表**对应命令行里 Agent 干活时列出的待办：Agent 把工作拆成几项时，输入框上方出现一行「任务 2/5 · 正在做的那项」，点开列出全部（已完成的划掉，进行中的高亮，被其他任务挡着的标「等待 #2」）。回合运行中默认展开、空闲时收起，全部完成且回合结束后自动隐藏（做完的计划在之后的回合里不再出现，新的计划单独显示）；有进行中的任务时，执行指示也改说这项任务。列表从空间里 Claude Code 自己保存的任务文件读取，刷新页面、空间停着都能看到；旧版 CLI 的 TodoWrite 取最近一次的完整列表，Codex 的计划（update_plan）同样显示，只算当前这一轮。

Claude Code 只对较早的模型（Claude 3.x、Opus / Sonnet 4.0～4.7、Haiku 4.5）默认启用任务工具，Claude 5 系列默认不用，这与命令行一致。想让 Claude 5 也列任务，在「系统设置 → 界面与提示」勾选「Claude 5 也使用任务列表」（按浏览器保存，从下一条消息起生效）；每次请求会多带任务工具、模型也会多几次调用来更新任务，可能多花一些 token。

**上下文占用**对应命令行状态栏（claude-hud）的上下文条：输入框右下角用圆环和百分比显示当前对话占了多少上下文窗口，70% 起变黄、85% 起变红，悬停（触屏点按）可看具体 token 数。数值取主对话最近一次模型请求的输入 + 缓存，随每次请求更新；子 Agent 和跑腿的上下文不算在内，压缩后显示压缩后的规模（旧版 Claude Code 不报时显示「—」直到下一次请求）。窗口大小以 Claude Code 每轮结束时报告的为准，新对话第一轮结束前只显示 token 数。Codex 空间同样显示，算法与 Codex 终端的「context left」一致（扣除约 12K 的固定开销后计算，所以和直接相除略有不同）；Codex 回退到 `codex exec` 时没有窗口信息，不显示。

Agent 用后台方式运行命令时，执行指示说明正在等待哪个后台任务；后台命令带「后台」标记，任务完成、失败或停止时在对话中留一行记录。主动停止回答后只显示一行「已中断」。

### `@` 引用文件

和命令行一样：在开头或空格后敲 `@`，边输入边按名字搜工作区里的文件和文件夹，对上的字加粗显示；↑↓ 选择、Tab 或 Enter 填入路径（不发送）、Esc 收起，选中文件夹会填入 `@文件夹/` 并接着列出里面的内容。路径相对工作区，含空格的写成 `@"my dir/a b.txt"`；Claude Code 会自己把文件内容（文件夹则是目录列表）带进这一轮。Codex 空间填入的是不带 `@` 的路径（与 Codex 自带的选择一致），由模型自己去读。

文件名由服务端直接读工作区，空间停着也能搜；遵守各目录的 `.gitignore`，跳过 `.git`、`node_modules` 等目录。工作区特别大时只搜靠上的几层，列表里会注明。

输入框里开头的命令、`@` 路径和粘贴图片或上传附件留下的 `[Image #1]` 占位显示成蓝底蓝字，附件占位填入后自动空一格。附件占位和写完的 `@` 路径按一个整体删除：退格或 Delete 碰到它就整块删掉，删附件占位时附件一起移除（撤销可恢复）；正在输入的 `@` 路径仍逐字删除。发出去以后，命令消息换成命令样式（等宽字、带提示符），`@` 路径显示成文件标签。

### 斜杠命令

在 Claude 空间的输入框里敲 `/`，会像命令行一样列出可用命令及说明：内置命令、技能、插件和项目自己的命令，读自空间里的 Claude Code，不请求模型。↑↓ 选择、Tab 填入、Enter 填入并发送、Esc 收起；只能在终端里用的命令不列出。运行中从菜单发出的命令排队，不引导进当前回合。

| 命令 | 在网页里的效果 |
| --- | --- |
| `/clear`（`/new`、`/reset`） | 由网页接管：新建对话。Codex 空间同样可用 |
| `/model`、`/effort` | 由网页接管：打开模型与推理强度选择。Codex 空间同样可用 |
| `/context` | Claude Code 本地作答，不请求模型也不扣费，画成与终端一样的格子图（按类别着色，附 MCP 工具、记忆文件、技能明细），回答底部标「未调用模型」 |
| `/usage` | 订阅账号本地作答，画成各额度窗口（当前会话、本周等）的进度条，重置时间按系统时区显示，下面列出用量构成 |
| `/compact` | 压缩期间显示「正在压缩上下文…」，完成后标出压缩前后的规模；压缩会请求一次模型，照常计费 |

其他命令按原样交给 CLI 执行。这些命令不会拿来给对话起标题，开着委派时也照样生效。`/compact` 与自动压缩的摘要请求、WebFetch 处理网页等 Claude Code 自己发出、不逐条上报的请求，服务端按 Claude Code 自己的累计用量对账后补记，照常计费。

### Agent 提问

Claude 执行中需要你拿主意时（它的 AskUserQuestion 工具），这一轮会停下来，对话里出现一张卡片，列出问题和选项（单选或多选，另有「其他」可自由填写）。提交后同一轮带着你的回答继续；点「跳过」或 10 分钟内没人回答，Agent 会按自己的判断继续并说明它的假设。多个页面同时打开时只认第一份回答，中断会撤回提问，等待的时间不计入回合时限。

只有 Claude 空间会提问，而且只在能显示卡片的页面发出的消息里；需要 Agent 镜像内的 Claude Code 支持 stream-json 输入与 `--permission-prompt-tool stdio`（默认固定镜像已支持）。

### 任务运行中继续发消息

Agent 干活时可以接着打字，输入框旁的按钮会换成当前的发送方式：

- **排队**（默认）：这一轮结束后把消息作为新一轮执行。排队的消息保存在服务端，关页面、服务重启后照常按顺序执行；遇到「结果不确定」的任务会等你核对后再开始；也可以从消息确认区撤回到输入框。
- **引导**：把消息插进正在跑的 Claude 这一轮，在当前这一步（比如正在跑的命令）结束后生效，并以虚线气泡显示在 Agent 实际接收它的位置；没来得及生效的会标「引导未生效」，可一键复制回输入框。

Ctrl/⌘+Enter 对单条消息用另一种方式，默认方式在「系统设置 → 界面与提示」里按浏览器设置。Codex 空间和即将结束的回合一律排队。

### 下一步提示

沿用 Claude Code 命令行的做法：Claude 空间每轮结束后，空输入框里以灰字显示预测的下一句，按 Tab（手机点「填入」）放进输入框，确认后再发送，不会自动发送。生成提示会多调用一次模型，费用计入额度并在使用记录里单独列为「下一步提示」；可在「系统设置 → 界面与提示」里按浏览器关闭。需要 Agent 镜像内的 Claude Code 支持 `--prompt-suggestions`，旧镜像不显示提示。

### 主管委派与扩展标记

**主管委派（开发预览）**让强模型带着便宜模型干活：在 Claude Code 空间的输入框旁打开「委派」并勾选跑腿模型，主 Agent（例如 Opus）照常对话、定方案、写关键代码，遇到规则明确的子任务（批量修改、按接口实现、补测试等）时通过平台工具交给 Sonnet、Codex 模型或中转模型去做。跑腿直接修改当前空间的文件，主 Agent 查看平台实测的改动后再汇报，过程以委派卡片显示在对话里；跑腿费用记在原空间下。没有可用跑腿时按普通对话执行并提示。管理员如何给模型标注任务类型、路由与 Jev 判断见[主管委派设计](architecture/delegation-supervisor.md)；不承诺省钱比例。

管理员启用的**扩展**作用于某个空间时，空间头部显示拼图图标，悬停列出扩展名称。例如「循环保护」会在模型反复输出同样的短句时中断这次回复并提示原因，随后短时间内拒绝相同的重试；它只作用于 Claude 与 Codex 的 API Key / 中转账号，不读取提示词与凭证。扩展的权限与范围见[扩展与 SPI](architecture/extensions-spi.md)。

### 图片与附件

点击对话输入框旁的回形针可添加图片或文件附件；在对话输入框或终端粘贴截图，可自动上传图片。对话中的占位标记会在发送时换成容器内路径，Agent 据此读取；终端直接收到图片路径，点击路径可预览。

聊天附件与文件上传共用系统设置中的「上传大小上限（MB）」（`max_upload_mb`，默认 512 MB），图片和 PDF 均适用。超限时可请管理员调整；反向代理 / CDN 的请求体限制也需允许相应大小。

图片位于用户的 `/shared/.images/`，文件附件位于 `/shared/.file/`。临时附件默认 48 小时后清理，仍被聊天记录引用的附件会保留。需要长期保留且不依赖聊天引用的文件，应复制到普通项目目录或共享目录。

## 终端

可以进入 Shell，也可以打开所选 Agent 的原版交互界面。容器内有 Git、Python 3、Node.js、编译工具与 tmux；额外依赖按项目需要安装。

工作空间镜像提供彩色 Shell 提示符、`ls` 配色与 `ll` 别名，以及完整 Vim（`vi` / `vim` 均可用）。颜色由命令自身输出，并非网页给所有文字自动上色。默认配置放在系统目录，用户可以用 `~/.bashrc` / `~/.vimrc` 覆盖；老容器需要更新镜像并重建后才会获得这些默认配置，仅重启网页服务不会更新容器里的工具。

Vim 中按 `i` 进入插入模式编辑，按 `Esc` 返回普通模式，再输入 `:wq` 保存退出或 `:q!` 放弃修改退出。冒号用于输入编辑器命令，不能直接在此输入正文。

「主终端」通过持久 tmux 会话 `main` 保持状态。刷新页面或短暂断线后重新连接，通常能回到原来的 Shell / CLI；停止或重建容器则会终止进程。主终端每个空间只有一个，在另一个页面或设备打开它会把这里顶下线。

### 多个终端标签

终端上方的标签栏可以同时开多个终端：点「+」选「Shell 终端」或「Claude Code / Codex CLI 终端」，新标签在工作区根目录打开 Shell，或直接启动该空间的 Agent。每个标签是独立的 tmux 会话，各自运行、互不顶号，适合把一个大任务拆成几条线并行推进；它们共用同一个 `/workspace`，可以通过文件交换计划和结果，但各自的对话上下文互不影响。多个 Agent 同时改同一个文件会互相覆盖，请按目录或文件分工。

- 切换标签不会中断其他标签里运行的程序，后台标签的输出切回来就能看到；刷新页面后标签仍在，打开时重新接上。
- 点标签上的 × 关闭：会结束该终端里运行的程序，屏幕内容不保留。主终端不能关闭。
- 程序退出（如 `exit` 或 Agent 退出）后标签停在「已断开」，点右侧重连按钮会在同一标签里重新打开 Shell 或 Agent。
- 网页新建的终端挂在工作区根目录项目下，桌面客户端里也能看到；桌面在其他项目里开的终端同样出现在这里，标签后面带项目名。同一个终端同一时刻只在一处显示。
- 每个空间最多 32 个独立终端（含桌面客户端开的）。终端里的用量与主终端一样补记。

镜像默认隐藏 tmux 状态栏并关闭前缀键，让按键直接传给 CLI。也可以在 Shell 里执行 `tmux new-window` 新建 tmux 窗口，但没有快捷键切换，更推荐用上面的标签。

账号环境、出口代理或内网隧道变更后，先重新连接网页终端，再新开 Shell（新标签或新窗口）以继承新环境；旧 Shell 不会自动更新环境变量。

顶栏「本空间已花」显示已入账的对话、起标题与支持的终端记录合计，每 15 秒轮询。支持 Claude 终端 transcript 与 Codex TUI rollout 补记，开启计量且有价格时入账即扣余额，详见[统计范围](usage-and-quotas.md)。

### 手机与触屏终端

终端底部提供 Esc、Tab、Shift+Tab、Ctrl+C、方向键和常用符号，横滑可查看更多。Ctrl / Alt 点亮后作用于下一次输入，再点可取消；右侧键盘按钮显示或收起软键盘。快捷键栏随可视区域调整，保留在软键盘上方；断线或图片上传期间暂时禁用。

在终端画面上单指上下滑动可翻看之前的输出，快速一甩会继续滑行，效果与电脑上的鼠标滚轮相同；双指缩放不受影响。往上翻时 tmux 进入历史浏览，这时输入的文字不会发给 CLI；滑回最底部或按快捷键栏的 Esc 即可回到输入状态。

长按终端画面约半秒会在手指上方弹出「粘贴」，把剪贴板里的文字送进当前程序（如 Claude 的输入框）；剪贴板里是图片时，与电脑上粘贴截图一样先上传，再输入容器内路径。读取剪贴板需要通过 HTTPS 访问：iOS 会再弹出系统的「粘贴」确认，Android 首次使用时会询问剪贴板权限。

## 文件与共享目录

文件页可以切换两个范围：

| 范围 | 容器路径 | 适用场景 |
| --- | --- | --- |
| 空间文件 | `/workspace` | 当前项目源码、依赖和输出 |
| 共享目录 | `/shared` | 跨空间交换文件、公共资料和交付包 |

支持上传普通文件、拖拽上传、上传进度、多选、新建文件夹、重命名、移动、删除、单文件下载和 ZIP 打包下载。支持解压 `.zip`、`.tar.gz`、`.tgz`、`.tar` 项目包，上传大小由 `max_upload_mb` 控制，默认 512 MB。

移动操作可在空间和共享目录间进行。删除目录会递归删除内容；上传时选择先清空目录，也会移除目标目录原有内容，操作前应确认范围。

手机端文件预览顶部第一行显示文件名、保存状态与关闭按钮，第二行提供预览 / 源码切换、刷新、保存及更多操作。下载、自动刷新和文件路径信息在「更多」中；正文独立滚动。

文本文件可以预览和编辑，Markdown 支持预览 / 源码切换，图片可以直接查看。保存单个文件内容的接口上限为 16 MB；Git、技能和普通文件预览各自还有不同的显示限制。

网页文件操作拒绝沿符号链接访问。保存采用原子替换，保留原文件可执行权限；同一文件的其他硬链接仍保留旧内容。上传压缩包先完整解压验证后再合并，格式错误不会覆盖原工作区；合并期间遇到磁盘错误或目录冲突仍可能留下部分已合并条目。需要沿链接操作时，可在终端内完成。

### HTML 预览

HTML 文件可以在预览窗口或新标签页打开，同目录的 CSS、JavaScript、图片通过短时只读预览链接加载。这适合查看 Agent 生成的静态页面与原型；它不会替你启动 Node / Python 应用服务器。

预览脚本在沙箱中执行，不能访问控制台的登录状态。预览使用的浏览器存储为临时内存，关闭即丢失，不能用来验证真实的持久登录流程。链接过期或服务重启后，从文件页重新打开即可；原始文件下载不受预览注入影响。

## 聊天草稿与消息确认

v0.1.11 网页的未发送输入支持按空间和对话恢复，可在输入框的「草稿与本机保存」关闭或清除保存。附件恢复会重新检查。发送前冻结副本，断线或刷新后按原请求 ID 查询；未知结果需核对，不自动重跑。范围见[聊天草稿与恢复](chat-recovery.md)。

## Git 变更审查

「变更」页显示仓库相对 `HEAD` 的已跟踪修改及未跟踪文件。工作区根目录不是仓库时，会继续寻找两层以内的子仓库；找到多个仓库时，在顶部选择目标仓库。

手机端在文件列表点击文件后进入差异详情，通过左上角返回按钮回到列表。克隆、Git 身份和丢弃全部改动收在「更多」中；远程状态默认只显示摘要，点击可展开地址与获取时间。无改动时显示单一空状态；空仓库提供克隆入口。

1. 在左侧选择文件，查看彩色 diff。
2. 切换「完整内容」阅读当前版本；新增文件默认显示内容。
3. 确认需要保留的改动，填写提交说明并提交。
4. 不需要的修改可以按文件或整个仓库丢弃。

提交会执行 `git add -A`，包含该仓库内所有待提交改动，提交前请审查整个列表。它只创建本地 Git commit，不会自动 push；推送通过「远程」中的连接、分支和目标确认后执行，也可使用终端。

Git 审查会按需启动空间，在该空间的容器内执行。额度已用完且开启拦截时，Git 命令与终端一样不可用，文件页仍可查看和下载。网页提交不运行 Git hook 或提交签名，需要这些功能时请在终端提交。Git 输出超过 4 MiB 会提示缩小范围或改用终端；单条命令限时 15 秒，超时后最多再等待 2 秒强制终止。

丢弃会恢复已跟踪文件并清理相应未跟踪文件，不能用它代替临时隐藏改动。大文件、二进制或超出列表上限的内容，可到终端进一步检查。

## 技能与界面偏好

Claude 空间的「技能」页可以查看技能文件树、上传技能、从官方插件目录提取技能，并在「本空间 / 我的模板」之间复制。安装到用户模板后，下次启动其他空间时同步；完整插件和 MCP 的说明见[技能手册](skills-and-mcp.md)。

桌面侧栏可以收起为图标栏；窄屏使用抽屉导航。主题支持跟随系统、浅色、深色；侧栏头像菜单里的「风格」可在琥珀（默认）、液态玻璃、赛博朋克、石墨极简、青野绿意、工程蓝图之间切换，与明暗互不影响，两项选择都只保存在当前浏览器。同一菜单底部的「管理主题…」可新建、编辑（实时预览）、导入、导出和删除自定义主题，见[界面主题](themes.md)。终端在所有风格下保持深色，只换底色色调和光标。侧栏头像菜单显示当前用户、角色和退出入口；下拉菜单支持方向键、Enter、Esc，较长的列表可搜索。

系统设置的管理分区仅向管理员开放；普通用户也能进入「界面与提示」，调整只在本浏览器生效的偏好：草稿本机保存、任务运行中继续发消息的默认方式、下一步提示、Claude 5 是否使用任务列表等。普通用户的账号选择、使用记录、共享目录与内网隧道仍可独立使用，遇到密码重置、账号不可用或额度不足时联系管理员。
