A 34-second silent browser tour with English and Chinese chapter captions. The README
uses a smaller [looping GIF](../images/tour.gif) for inline playback; the MP4 retains more
detail. The chapter strip sits above the unmodified product UI.

合成演示数据；未连接生产、未调用模型，也不展示真实用户数据。

Desktop screenshots are **2880 × 1920** PNGs, captured at 2× pixel density. The mobile
screenshot is **780 × 1688**. The MP4 is **1440 × 1072**, including the caption strip,
encoded as H.264/yuv420p with faststart. See [capture.json](capture.json) for the source
revision, dimensions, and exact chapter times.

The architecture illustrations are editable [English](../images/architecture.svg) and
[Chinese](../images/architecture-cn.svg) SVGs. They remain sharp at any zoom level.

To regenerate these assets, follow the [capture guide / 素材生成说明](../development.md#文档截图).
