# 界面多语言

Agentbox v0.1.10 的网页版与 abox-link 本机面板支持简体中文（`zh-CN`）、繁體中文（`zh-TW`）和 English（`en`），并提供「跟随系统」。当前桌面源码也接入同一套语言能力，但已发布的 Desktop 0.1.2 安装包尚不包含它。

## 发布范围与入口

| 界面 | v0.1.10 发布情况 | 语言入口 |
| --- | --- | --- |
| 网页控制台 | 随服务端包发布 | 登录页、登录后的用户菜单 |
| abox-link 本机面板 | 随五个平台的 abox-link 包发布；服务端也提供对应下载 | 面板顶部，配对前即可使用 |
| 桌面客户端 | 当前源码已实现，本次不发布新的原生安装包 | 源码构建中的登录页、客户端设置 → 外观 |

服务端升级不会更新本机正在使用的 abox-link 或桌面应用。旧 abox-link 需下载并运行 v0.1.10 才能获得多语言面板；`desktop-v0.1.2` 继续使用原界面，后续桌面包另行发布。桌面构建和验收边界见[桌面指南](../desktop/README.md)。

语言菜单在登录或配对前即可使用，选择后即时更新界面，无需刷新、重新登录或重连终端。网页语言行与其他用户属性对齐，鼠标操作使用紧凑下拉，触屏保留较大的点击区域。

## 选择与兼容

- 首次使用按浏览器／系统语言列表顺序选择支持的语言；例如 `en-US` 使用英语，`zh-Hant`、`zh-HK`、`zh-MO` 使用繁体中文，`zh`、`zh-Hans` 使用简体中文。显式文字体系优先于地区，例如 `zh-Hans-HK` 使用简体中文。
- 用户显式选择优先于系统语言。系统语言均不支持时使用英语；个别词条缺失时回退到源文案（简体中文），不显示内部键名。
- 语言保存在当前浏览器／设备的 localStorage 中。网页版和桌面使用 `agentbox.language`，abox-link 面板使用 `abox_link_language`。不同来源和设备的存储相互独立，本次不增加服务端个人偏好字段或数据库迁移，也不跨设备同步。
- 存储被禁用或不可写时，本次运行仍可切换语言，只是不保证重开后记住选择。同一来源的其他窗口更改偏好，以及「跟随系统」时系统语言变化，都会更新当前界面。
- 语言仅改变界面展示。现有服务端 API、终端消息、配对协议与数据格式不变，可继续连接原有服务端。

服务器返回的诊断、运行日志、用户创建的名称和文件内容保留原文。界面语言不决定 Claude / Codex 的回答语言，也不翻译终端输出。服务端配置的系统时区仍是日期查询与计费时间的依据，切换语言不能改动它。

## 实现结构

`web/src/i18n/core.ts` 是三个界面共用的无依赖核心，负责语言归一化、系统检测、本地偏好、词典查找和一次性参数插值。

| 界面 | 接入方式 | 词典 |
|---|---|---|
| 主控制台 | `web/src/i18n.ts`：显式 DOM 文案／属性绑定和语言切换事件 | `web/src/locales/` 中的静态、动态词典 |
| 桌面客户端 | `desktop/src/i18n.ts`：Vue 响应式适配，直接导入共享核心 | `desktop/src/locales/` |
| abox-link | `internal/linkapp/static/app.js`：显式标记静态文案，按状态渲染动态文案 | `internal/linkapp/static/locales/en.js`、`zh-TW.js` |

主控制台继续使用原生 ES Module：TypeScript 逐文件编译到 `internal/web/static/js/`，随 Go 二进制嵌入，不额外引入 React 或打包器。构建时还会将编译后的共享核心同步到 `internal/linkapp/static/i18n-core.js`，供独立嵌入资源的 abox-link 使用；该文件应由构建生成，不手工修改。前端源码、词典和生成产物需一并提交。

语言切换只更新拥有明确来源的界面文本和属性。不可按中文字符或词典命中结果遍历翻译所有 DOM；例如用户名恰好为「保存」时，仍须显示用户的原始名称。也不可修改 DOM 全局原型来拦截任意 `textContent`／`innerHTML` 写入。

abox-link 的规则列表保留原有草稿机制：规则内容没有变化时不重建输入框。语言切换更新标签、按钮和辅助属性，保留未保存地址、复选框、焦点与选择区，不调用保存、启动、停止或配对接口。后端错误和日志始终走纯文本展示。

## 添加与维护文案

1. 简体中文源文案作为键，补齐 English 与繁体中文两个词典。句子用完整模板和命名参数，例如 `已连接 {duration}`，避免在界面代码里拼接语序。
2. 新界面文本必须通过该界面的翻译适配层或显式标记接入；辅助标签、工具提示、占位提示和移动端表格字段名也属于界面文案。
3. 文件名、主机名、模型输出、源代码、凭证、用户输入和服务器原始诊断只能作为参数或原始数据，不作为词典键批量替换。
4. 翻译本身不作为 HTML 执行。优先设置文本节点；确需 HTML 模板时，对参数保持原有转义边界。占位符只替换一轮，参数中的 `{name}` 不应被再次解释。
5. 不翻译用于协议或内部判断的固定值。例如 `online`、`stopped`、`auth_failed`、路径、字段名，以及历史对话附件标记中的固定文本都保留原值，单独翻译它们的展示标签。
6. 切换语言不应刷新整个页面、重新挂载终端、保存表单草稿，或清空正在编辑的内容。修改相关组件时验证这些行为。

## 验证

基础构建与类型检查：

```bash
npm run check
npm run build
npm run test:i18n
npm --prefix desktop run check
npm --prefix desktop run build
npm --prefix desktop run test
go test ./internal/linkapp ./internal/web
```

abox-link 的独立浏览器验收使用合成 API，不启动真实隧道或使用真实凭证。先安装或指定 Playwright，再运行：

```bash
# playwright 已在当前 Node 模块搜索路径中时
node scripts/test-link-i18n.mjs

# 沿用仓库其他浏览器脚本的外部安装方式时
AGENTBOX_PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs \
  node scripts/test-link-i18n.mjs
```

脚本检查三种语言、配对前后的切换、语言持久化、状态和动态提示、草稿与输入节点/光标保留、原始日志/诊断/目标地址不变、字典参数一致性，以及 1280、390、320 像素宽的英语布局。截图写入 `output/playwright/link-i18n-english-mobile.png`。

主控制台自动验收：

```bash
AGENTBOX_PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs node scripts/test-web-i18n.mjs
AGENTBOX_PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs node scripts/test-browser.mjs
AGENTBOX_PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs node scripts/test-git.mjs
```

`test-web-i18n.mjs` 验证实际语言控件、同源窗口偏好同步、表单输入与焦点保留、图标与忙碌按钮恢复、终端实例与连接保留、用量原节点与金额快照、日期草稿与系统时区，以及英文窄屏布局。`test-i18n.mjs` 验证语言回退、禁写存储、词典覆盖、占位符与两份嵌入核心一致性。桌面 `i18n.test.ts` 检查响应式提示、终端字节与连接、不可逆操作确认文本和两种词典。

主控制台与桌面的后续改动也应覆盖：未登录时切换、隐藏页面和异步弹窗显示、英文长标签、无障碍名称、终端不断线、配置草稿保留、系统时区不变、浏览器存储失效与未知语言回退。既有只断言中文文案的测试应显式设置 `zh-CN` 基线，避免测试结果依赖运行机器的语言。
